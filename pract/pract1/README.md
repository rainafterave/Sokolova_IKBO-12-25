# Практическая работа №1. Эмулятор UNIX

Вариант 23, этапы 1–4.

Программа на Python с графическим окном. Пользователь вводит команды,
а программа выполняет их и показывает результат: например, список файлов,
текущую дату или историю команд.

Виртуальные папки и файлы описаны в CSV. При запуске программа загружает
их в память. Все переходы между папками происходят внутри этой виртуальной
файловой системы. Исходный CSV остается без изменений.

## Что сделано

1. Создано окно для ввода команд. Добавлен разбор кавычек и вывод ошибок.
   В первых двух этапах команды `ls` и `cd` работают как заглушки.
2. Добавлены параметры запуска и выполнение команд из текстового файла.
   При первой ошибке выполнение такого файла останавливается.
3. Подключена виртуальная файловая система из CSV и переходы между папками.
4. Добавлены команды просмотра файлов, времени работы, истории и даты.

## Как запустить

Нужен Python 3.10 или новее с Tkinter. Дополнительные библиотеки
устанавливать не требуется.

Из корня репозитория в PowerShell:

```powershell
cd pract/pract1
.\run.bat
```

Откроется окно с полной версией программы и примером файловой системы.
Вводить команды можно в нижней строке окна, подтверждать — клавишей Enter.
На Linux и macOS для запуска используется `sh run.sh`.

## Команды

| Команда | Что делает |
|---|---|
| `ls [путь]` | Показывает файлы и папки. Без пути — в текущей папке |
| `ls -a` | Показывает также скрытые файлы |
| `ls -l` | Показывает тип, размер и имя. Можно объединить флаги: `ls -al` |
| `cd [путь]` | Переходит в папку. `cd ..` — на уровень выше, `cd` — в корень |
| `uptime` | Показывает, сколько времени работает эмулятор |
| `history [N]` | Показывает всю историю команд или последние N команд |
| `date` | Показывает дату и время. `date -u` — время в UTC |
| `exit` | Закрывает программу |

Можно задать формат даты: `date "+%Y-%m-%d %H:%M:%S"`.
Пути внутри эмулятора записываются через `/`, а названия с пробелами —
в кавычках. Например, в окне программы можно ввести:

```text
ls
cd /home/student
cd "My Documents"
ls
cd ..
date
history
```

## Параметры запуска

- `--vfs ПУТЬ` — выбрать CSV с виртуальными файлами и папками.
- `--script ПУТЬ` — выполнить команды из текстового файла перед ручным вводом.
- `--stage N` — показать этап 1, 2, 3 или 4. По умолчанию выбран этап 4.
- `--headless` — выполнить сценарий без окна для автоматической проверки.
  Используется вместе с `--script`.
- `--help` — показать справку по запуску.

Пример запуска с готовыми данными и командами:

```powershell
.\run.bat --vfs vfs-samples/deep.csv --script scripts/interactive.txt
```

В начале работы показываются выбранные параметры. Сценарий выполняет
команды по очереди; при ошибке сообщает номер строки и останавливается.
После этого в окне можно продолжить ввод вручную. Команда `exit` закрывает
программу, в том числе при выполнении сценария.

## Что находится в папках

- `src` — код программы: запуск, окно, настройки, разбор и выполнение команд,
  загрузка файловой системы и выполнение сценариев.
- `scripts` — готовые сценарии для четырех этапов и демонстрации.
  В `scripts/errors` находятся команды с намеренными ошибками.
- `tests` — проверки команд, настроек, окна и файловой системы.
- `vfs-samples` — три примера CSV: пустая система (`minimal.csv`),
  несколько файлов (`several.csv`) и вложенные папки (`deep.csv`).

В CSV каждая строка содержит путь, тип объекта (`dir` — папка,
`file` — файл) и его данные. Содержимое файлов записано в base64 —
это способ представить любые байты обычным текстом.

## Как проверить

Команды выполняются из папки `pract/pract1`:

```powershell
py -3 -m unittest discover -s tests -v
```

Отдельная проверка графического окна:

```powershell
py -3 -m unittest tests.gui_smoke -v
```

Для проверки запусков в Windows есть файлы `tests/test_config.bat`,
`tests/test_vfs.bat` и `tests/test_commands.bat`.
